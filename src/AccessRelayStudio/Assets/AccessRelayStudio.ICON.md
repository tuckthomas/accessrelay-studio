# AccessRelay Studio icon

Generated using the built-in ImageGen tool in transparent-background mode. The PNG is used by the window and sidebar. The ICO contains nine sizes from 16 through 256 px and is embedded in the Windows executable.

## Prompt

> Create a single Windows application icon for AccessRelay Studio, an assistive desktop app for accessible controller input, input customization, and voice communication. Design one clear inclusive symbol: two gently curved open paths meeting at one bright point, resembling a person with open arms and a small signal wave at once. The symbol should suggest connection and agency. Center the bold simple symbol in a dark slate-blue softly rounded square with generous transparent margin on a square transparent canvas. Use high-contrast light mint and warm soft white, thick contours, and deliberate negative space. Flat modern desktop icon, readable at 16 pixels, no writing, no initials, no gamepad, no target, no masks, no gaming imagery, no photorealism, no shadows outside the tile.
